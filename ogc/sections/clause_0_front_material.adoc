GeoParquet 2.0 is built on the geospatial logical types `GEOMETRY` and `GEOGRAPHY` and the geospatial statistics that Apache Parquet added in format version 2.11 (March 2025). The Parquet format specification is therefore a normative reference of this Standard: this Standard does not redefine the encoding of geometries, the syntax of the Parquet `crs` parameter or the edge interpolation algorithms, but requires their use and specifies the additional GeoParquet metadata and the consistency between that metadata and the Parquet schema.

== Abstract

Apache Parquet is a standardized open-source columnar storage format. GeoParquet specifies how geospatial vector data is stored in Parquet files: geometry columns use the Parquet `GEOMETRY` and `GEOGRAPHY` logical types with Well-Known Binary (WKB) values, and a `geo` entry in the Parquet file metadata carries additional metadata about each geometry column, such as the geometry types present, the coordinate reference system, the coordinate epoch, the edge interpolation, the polygon orientation and the bounding box. This Standard defines the requirements that a Parquet file has to satisfy to be a GeoParquet 2.0 file, in two requirements classes: Core, which applies to every GeoParquet file, and Bounding Box Covering, which applies to files that additionally store a per-row bounding box column for accelerated spatial filtering.
